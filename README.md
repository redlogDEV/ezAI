# 🤖 Russian Chatbot & NLP Pipeline

Простой чат-бот на русском языке и NLP пайплайн, написанные на чистом Python без тяжёлых зависимостей. Работает на телефоне (Termux / Pydroid 3).

---

## 📁 Структура проекта

```
├── chatbot.py           # Чат-бот на основе датасета
├── nlp_pipeline.py      # Токенизация → Эмбеддинги → Softmax
├── dataset_part1.txt    # Датасет диалогов (часть 1)
├── dataset_part2.txt    # Датасет диалогов (часть 2)
├── dataset_part3.txt    # Датасет диалогов (часть 3)
└── vocabulary.txt       # Словарь для NLP пайплайна
```

---

## 💬 Чат-бот (`chatbot.py`)

Бот ищет наиболее похожий вопрос в датасете и возвращает готовый ответ. Использует косинусное сходство TF-векторов — без нейросетей, без интернета.

### Возможности
- Загружает несколько датасетов сразу
- Автоматически определяет кодировку файлов (UTF-8, Windows-1251)
- Сохраняет историю диалогов в `chat_history.json`
- Работает полностью офлайн
- Только стандартная библиотека Python — ничего устанавливать не нужно

### Запуск
```bash
python chatbot.py
```

### Команды внутри чата
| Команда | Действие |
|---|---|
| `история` | Показать последние 10 сообщений |
| `выход` | Завершить диалог |

### Пример диалога
```
Ты: Привет! Как дела?
Бот: Привет! Всё отлично, спасибо что спросил. А у тебя как?

Ты: Как научиться программировать?
Бот: Лучший способ — сразу писать маленький проект, а не проходить курсы до конца.
```

## 🧠 NLP Пайплайн (`nlp_pipeline.py`)

Учебный пример базового NLP пайплайна — показывает как устроена обработка текста внутри нейросетей.

### Шаги пайплайна

```
vocabulary.txt → токенизация → эмбеддинги → softmax
```

| Шаг | Файл на выходе | Что внутри |
|---|---|---|
| Загрузка словаря | `vocabulary.txt` | Список слов |
| Токенизация | `tokens.json` | `{"слово": id}` |
| Эмбеддинги | `embeddings.json` | `{"слово": {"vector": [...]}}` |
| Softmax | `softmax_output.json` | Вероятностное распределение |

### Запуск
```bash
python nlp_pipeline.py
```

> Если словарь в кодировке Windows-1251 — скрипт конвертирует автоматически.

## 📊 Датасет

Два файла диалогов на русском языке общим объёмом ~20 МБ. Темы: обучение, продуктивность, программирование, здоровье, наука, психология и другое.

### Формат
```
USER: Вопрос пользователя
ASSISTANT: Ответ бота

---

USER: Следующий вопрос
ASSISTANT: Следующий ответ
```

### Добавить свои данные
Просто добавь новые диалоги в `dataset_part1.txt` или `dataset_part2.txt` в том же формате, либо создай новый файл и добавь его имя в список `DATASET_FILES` в начале `chatbot.py`.

## 📌 Заметки

Это учебный / экспериментальный проект. Чат-бот работает по принципу поиска похожего вопроса, а не генерации текста. Для полноценной языковой модели потребуется обучение на GPU и значительно больший датасет.
